# Brand identity — the mark, the icons, the menu-bar glyph

Status: done — mark chosen (B), pipeline landed, tray and Electron wired (2026-08-28)

Sources of truth: `CONTEXT.md` (glossary — its vocabulary is normative in any brand copy), ADR-0001/0020/0034 (the promise the mark must not contradict: local-only, inert, provable), ADR-0016 (Developer ID, direct download), ADR-0025 (Windows is a ship gate), ADR-0033 (the repo goes public at M2 — the mark will be a public artifact). Plan of record: `~/.claude/plans/valiant-twirling-perlis.md` (2026-08-28).

## Problem Statement

The repo has no brand asset of any kind. The menu-bar item — the Core's only face today — is the text `●`/`○`; the Electron window shows Electron's own icon; there is no favicon, no app icon for either platform, nothing for the iOS/Android clients or the website that follow. Packaging (M5) will need an `.icns` and an `.ico` on day one, and the public repo (M2) needs a mark on its README.

## Solution

One mark, drawn as a monoline glyph on a 256-unit grid, from which everything else is generated by one script (`brand/render.mjs`): the macOS icon (`.icns` and a macOS 26 Icon Composer `.icon` package), Windows `.ico`, iOS `AppIcon.appiconset` (with iOS 18 dark and tinted appearances), Android adaptive icon, the web favicon set, four 18-pt template states for the menu bar, and a wordmark/lockup. Generated files are committed; the script is the source of truth and re-running it must produce no diff.

## What was borrowed, and from where

Three installed competitors were studied bundle-by-bundle before drawing (details in the plan):

- **Granola** — one abstract glyph on one flat colour; the *same* glyph is the template menu-bar item; a two-layer (fill + glyph) construction so dark and tinted variants are free. Taken.
- **Anarlog** — a letterform-plus-cursor mark; a tray whose glyph *changes with state*; a dark-mode icon variant. Taken as ideas; its cream/yellow tile with a lowercase letter and underscore is avoided, because it is a direct competitor's identity.
- **Meetily** — wordmark, mascot and tagline inside the app icon (illegible at 32 px); the full-colour icon reused as the tray image. Left.

## Design brief

- **Says:** speech becomes a kept record. **Never:** clouds, sync arrows, globes, padlocks, sparkles — the product's promise is that nothing leaves.
- **Construction:** `viewBox 0 0 256 256`, one stroke weight (32) with round caps and joins, ink within 32–224; one colour, no gradient on the glyph. A small-size variant (stroke 40, less detail) serves every raster ≤ 32 px. The glyph must read as a monochrome template at 16–18 pt with alpha only.
- **Palette:** `teal-400 #158580` (tile top), `teal-500 #0F6E6A` (base), `teal-700 #094F4C` (tile bottom / dark tile), `paper #F5F1E8` (glyph on tile), `ink #1F1D1B` (glyph on light), `record #E5484D` (recording accent in UI only — never on the icon).
- **Three candidates** are rendered first (A voice-line, B letterform "e", C open loop-into-line) and the Operator of this repo picks; everything else is generated from the winner.
