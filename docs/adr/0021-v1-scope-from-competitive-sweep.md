# v1 scope additions and non-goals from the competitive sweep (2026-07-09)

Adopted into v1, closing the gap analysis against Granola / anarlog / Meetily (`docs/competitive-facts-2026-07-09.md`):

- **Action items in Summary** — the single v1 Summary template ends with an action-items section extracted from Transcript + Notes. Extraction only; pushing items to external tools is a non-goal.
- **Custom prompt for Summary** — Summary exposes its system prompt as an editable settings field with reset-to-default. No mode library.

Ratified non-goals: mobile apps, team spaces/sharing/roles, coaching analytics, CRM/task-manager push, PDF/DOCX export (the Markdown mirror is the export), summary-template library, auto-joining meetings (dead under ADR-0020 regardless), and import of external audio files (post-v1, arriving with the Enhance family unlocked by ADR-0019).
