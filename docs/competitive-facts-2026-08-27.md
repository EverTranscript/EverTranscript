Per-product notables:

- **Granola**: ~16 native N-API addons plus dedicated Electron `utilityProcess` children (audio, local ASR, local diarization, SQLite, TCC); encrypted SQLite (better-sqlite3-multiple-ciphers) behind a single `sqlite_process` — single-writer discipline enforced by process boundary; summaries via Granola's own cloud LLM proxy (meeting content leaves the machine); virtual-camera **system extension** (in-meeting watermark), screen OCR of shared screens, global keystroke helper for hotkeys, Zoom/Teams UI automation via Accessibility; models fetched from CloudFront at runtime; not App-Sandboxed; Sentry + Amplitude + Segment + Statsig.
- **anarlog**: Erlang-style actor/supervisor runtime (ractor); embedded two-stage DTLN-style **AEC** + denoiser ONNX + ebur128 loudness; dual-track WAV recording → Ogg Vorbis; sqlx SQLite (62 migrations) + tantivy FTS + CRDT cloud sync (sqlite-sync) + own E2EE layer; **in-process llama.cpp removed** (stubbed) in favor of Ollama / LM Studio / Apple Foundation Models; hosted summaries via OpenRouter (Claude Sonnet); tauri-specta typed IPC; **Windows mic detection is a no-op stub**.
- **Meetily**: `llama-helper` **sidecar** (llama.cpp, JSON over stdio, spawn-on-demand, idle-timeout) for built-in summaries; **bundled ffmpeg** for AAC/mp4 with crash-safe chunk-and-merge recording; RNNoise + ebur128 but **no AEC** (documented Bluetooth/audio-quality complaint class); plaintext API keys in SQLite; GPU support as compile-time cargo features — their top complaint pile; models from Hugging Face + a first-party mirror.
- **codex app-server** (architecture reference, not a competitor): one `MessageProcessor` behind four bindings — spawned stdio child (JSONL), in-process typed channels (their CLIs embed the server), **UDS daemon serving 0..N clients** (0600 socket, startup lock), remote relay; macro-defined protocol tables + ts-rs/schemars codegen with committed, test-enforced fixtures; per-connection initialize + experimental-API gating; thread-scoped vs broadcast fanout with subscription sets and request replay on late attach; **threads keep running at zero clients**; daemon-lifecycle crate is Unix-only; backpressure tuned for interactive traffic (128-message queues, disconnect-on-full).

Corrections vs 2026-07-09: **anarlog is no longer "thin"** — it ships cross-meeting voiceprints, channel attribution, notes/summaries, a CLI, and an MCP server (though its *local* multi-speaker clustering is a stub; that remains cloud-side, per the 2026-08-27 deep-mine). Our verified differentiators, post-sweep: the **Closed Boundary** (all three ship cloud paths for meeting content), **silent Auto-Record** (anarlog prompts per meeting; Granola leans on calendar + cloud; Meetily CE has none), the **always-on Rust Core daemon + query CLI** (nobody runs a daemon; Granola pays full-Electron-at-login instead), and **working Windows detection** (anarlog's is a stub). Detection-with-local-only-storage remains uncontested.

Adopted implications live in ADR-0027–0032.
